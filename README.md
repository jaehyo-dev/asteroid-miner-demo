# 소행성 광부 (Asteroid Miner) — 웹 데모

픽셀 아트 로그라이트 채굴 슈터입니다. 소행성을 부수며 광물을 모으고, 몰려오는 적을 버티다가 귀환 게이트로 돌아가 기지를 키워 나갑니다.

- 플레이: https://jaehyo-dev.github.io/asteroid-miner-demo/
- 이전 버전: https://jaehyo-dev.github.io/asteroid-miner-demo/versions/
- 스팀 얼리 액세스 출시 예정 (2027년)

## 이 저장소에 대해
